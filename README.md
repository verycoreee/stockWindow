# StockWindow

轻量、低调、可扩展的 Windows 11/10 任务栏实时股票行情小工具（Python + PySide6）。

设计初衷是替代只用到了其中股票插件的重型任务栏监控软件，重点解决两个日常痛点：
1. **低调自定义外观**：默认纯色低对比度字体融入任务栏（告别刺眼红绿），同时支持自由调整颜色、字体、字号、透明度与自定义简称。
2. **中文/拼音直接搜股**：添加自选时直接输入中文名称、拼音首字母或代码即可模糊搜索添加（支持 A 股、ETF、指数、港股、美股），不再需要先查带市场前缀的代码。

---

## 主要特性

- **任务栏左下角贴靠**：无边框、不抢焦点、不进 `Alt+Tab`，默认贴靠 Windows 任务栏左下角，可微调偏移或解锁后鼠标直接拖拽定位。
- **上班友好细节**：
  - 默认「低调纯色模式」，也可切换为「自定义涨跌色」（自定义涨/跌/平三种颜色）
  - 支持每只股票设置低调别名/简称（例如自定义缩写），以及仅显示简称 + 涨跌幅
  - **全屏自动隐藏**（看视频/演示时自动收起）
  - **全局老板键**（默认 `Ctrl+Alt+H` 一键隐藏/恢复，支持在设置中开关）
  - 鼠标悬停显示完整行情详情（现价、昨收、涨跌额、涨跌幅、更新时间），支持鼠标滚轮翻页或定时轮播
- **分层可扩展架构**：数据源、格式化配色、Win32 任务栏适配与 UI 严格解耦，详见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 快速启动（Windows）

### 1. 初始化虚拟环境与依赖

```powershell
.\scripts\setup.ps1
```

或手动执行：

```powershell
python -m venv .venv
.\.venv\Scripts\pip.exe install -r requirements-dev.txt
```

### 2. 运行程序

```powershell
# 推荐：后台无黑框启动
.\scripts\start.ps1

# 或前台调试启动（可在终端看到日志）
.\.venv\Scripts\python.exe -m stock_window
```

> 首次启动会在本地生成 `data/config.json`（该目录已在 `.gitignore` 中忽略，不会被提交到 Git）。

### 3. 运行单元测试

```powershell
.\.venv\Scripts\pytest.exe
```

## 日常操作说明

- **右键任务栏股票条 / 右键右下角托盘图标**：打开「自选管理」「外观与行为设置」「解锁/锁定拖拽」「立即刷新」「隐藏/显示」「退出」。
- **拖动位置**：右键勾选「解锁拖拽」后按住股票条拖到任务栏左下角或任意喜欢的位置，松手即保存，再勾回锁定防误触。
- **滚轮切换**：自选数量大于单屏最大可见条数时，在股票条上滚动鼠标滚轮可手动翻页（也可在设置中开启自动轮播）。
- **老板键**：默认 `Ctrl+Alt+H` 立即隐藏/显示任务栏股票条。
